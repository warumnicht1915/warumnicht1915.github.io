이 저장소에만 권한을 준 Fine-grained 토큰을 넣어주세요. 토큰은 이 브라우저에만 저장되며 어디로도 전송되지 않습니다 (GitHub API 호출에만 쓰입니다).

토큰 만드는 법 (1분)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 블로그 저장소 하나만 선택
  3. Permissions → Repository permissions → Contents: Read and write (이것 하나면 충분합니다)
  4. 만료일은 짧게 잡으세요. 만료되면 여기서 새 토큰으로 바꾸면 됩니다.

공용 PC에서는 쓰지 마세요. 토큰이 브라우저에 남습니다. 자리를 뜰 때는 아래 로그아웃으로 지우세요.
